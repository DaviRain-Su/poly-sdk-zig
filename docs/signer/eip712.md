# EIP-712 类型化结构数据签名

> 实现 EIP-712 标准的结构化数据哈希和签名。

## 概述

EIP-712 定义了一种结构化数据的签名标准，使得签名更加安全且用户可读。Polymarket 使用 EIP-712 签名订单。

### 签名流程

```
1. 定义类型 (types) 和域分隔符 (domain)
2. 计算类型哈希: typeHash = keccak256(encodeType(typeName))
3. 计算数据哈希: hashStruct(typeName, data)
4. 计算最终摘要: keccak256("\x19\x01" || domainSeparator || structHash)
5. 使用私钥签名摘要
```

## 核心类型

### Domain（域分隔符）

```zig
pub const Domain = struct {
    /// 域名称
    name: ?[]const u8 = null,
    /// 版本
    version: ?[]const u8 = null,
    /// 链 ID
    chain_id: ?u256 = null,
    /// 验证合约地址
    verifying_contract: ?[20]u8 = null,
    /// 盐值
    salt: ?[32]u8 = null,
};
```

### TypeField（类型字段）

```zig
pub const TypeField = struct {
    /// 字段名
    name: []const u8,
    /// 字段类型
    type_name: []const u8,
};
```

### Order（Polymarket 订单）

```zig
pub const Order = struct {
    salt: u256,           // 随机盐值
    maker: [20]u8,        // 订单创建者地址
    signer: [20]u8,       // 签名者地址
    taker: [20]u8,        // 接单者地址（0x0 表示任何人）
    token_id: u256,       // 代币 ID
    maker_amount: u256,   // 创建者数量
    taker_amount: u256,   // 接单者数量
    expiration: u256,     // 过期时间（0 表示永不过期）
    nonce: u256,          // 防重放
    fee_rate_bps: u256,   // 手续费率（基点）
    side: u8,             // 0=BUY, 1=SELL
    signature_type: u8,   // 0=EOA, 1=POLY_PROXY, 2=POLY_GNOSIS_SAFE
};
```

## 编码函数

### encodeType

编码类型字符串：

```zig
var buffer: [512]u8 = undefined;
const type_str = encodeType(&ORDER_TYPE, &buffer);
// "Order(uint256 salt,address maker,address signer,...)"
```

### encodeDomainType

编码域类型字符串：

```zig
const domain = Domain{
    .name = "Polymarket CTF Exchange",
    .version = "1",
    .chain_id = 137,
};
var buffer: [256]u8 = undefined;
const type_str = encodeDomainType(&domain, &buffer);
// "EIP712Domain(string name,string version,uint256 chainId)"
```

### 值编码函数

```zig
// uint256 编码为 32 字节大端序
const encoded = encodeUint256(12345);

// 地址编码为 32 字节（左填充零）
const encoded = encodeAddress(&addr);

// 字符串编码为 keccak256 哈希
const encoded = encodeString("hello");

// bytes32 直接复制
const encoded = encodeBytes32(&data);

// bool 编码为 32 字节
const encoded = encodeBool(true);

// uint8 编码为 32 字节
const encoded = encodeUint8(1);
```

## 哈希函数

### typeHash

计算类型哈希：

```zig
const hash = typeHash("Order(uint256 salt,...)");
```

### hashDomain

计算域分隔符哈希：

```zig
const domain = createPolymarketDomain(POLYGON_CHAIN_ID, false);
const domain_separator = hashDomain(&domain);
```

### hashOrder

计算订单结构体哈希：

```zig
const order = Order{ ... };
const struct_hash = hashOrder(&order);
```

### hashTypedData

计算 EIP-712 最终签名摘要：

```zig
const digest = hashTypedData(&domain_separator, &struct_hash);
// digest = keccak256("\x19\x01" || domainSeparator || structHash)
```

## Polymarket 特定功能

### 合约地址常量

```zig
// 主网 (Polygon, chainId=137)
pub const CTF_EXCHANGE_ADDRESS_MAINNET: [20]u8;
pub const NEG_RISK_CTF_EXCHANGE_ADDRESS_MAINNET: [20]u8;

// 测试网 (Amoy, chainId=80002)
pub const CTF_EXCHANGE_ADDRESS_AMOY: [20]u8;
pub const NEG_RISK_CTF_EXCHANGE_ADDRESS_AMOY: [20]u8;

// 链 ID
pub const POLYGON_CHAIN_ID: u256 = 137;
pub const AMOY_CHAIN_ID: u256 = 80002;
```

### createPolymarketDomain

创建 Polymarket 域分隔符：

```zig
// 主网普通交易
const domain = createPolymarketDomain(POLYGON_CHAIN_ID, false);

// 主网 Neg Risk 交易
const domain = createPolymarketDomain(POLYGON_CHAIN_ID, true);

// 测试网
const domain = createPolymarketDomain(AMOY_CHAIN_ID, false);
```

### hashPolymarketOrder

一站式计算 Polymarket 订单签名摘要：

```zig
const order = Order{ ... };
const digest = hashPolymarketOrder(&order, POLYGON_CHAIN_ID, false);
```

## 完整示例

```zig
const poly = @import("poly-sdk-zig");
const signer = poly.signer;

// 1. 创建钱包
const wallet = try signer.Wallet.fromPrivateKeyHex("0x...");

// 2. 创建订单
const order = signer.Order{
    .salt = generateRandomSalt(),
    .maker = wallet.address_bytes,
    .signer = wallet.address_bytes,
    .taker = [_]u8{0} ** 20,  // 任何人可接单
    .token_id = 12345,
    .maker_amount = 100_000000,  // 100 USDC (6 decimals)
    .taker_amount = 65_000000,   // 65 shares
    .expiration = 0,  // 永不过期
    .nonce = 0,
    .fee_rate_bps = 0,
    .side = 0,  // BUY
    .signature_type = 0,  // EOA
};

// 3. 计算签名摘要
const digest = signer.hashPolymarketOrder(&order, signer.POLYGON_CHAIN_ID, false);

// 4. 签名
const signature = try wallet.sign(&digest);

// 5. 验证（可选）
const is_valid = wallet.verify(&digest, &signature);
```
