## 目标

实现市价单创建功能，支持 FOK (Fill Or Kill) 和 FAK (Fill And Kill) 订单类型。

## 需求

市价单是一种以当前市场价格立即执行的订单。与限价单不同，市价单不指定固定价格，而是根据订单簿深度计算最优价格。

```zig
const poly = @import("poly-sdk-zig");
const Decimal = poly.types.Decimal;

// 首先获取订单簿
const book = try client.getOrderBook("123456789");
defer book.deinit();

// 创建 FOK 市价买单（全部成交或取消）
const fok_order = try client.createMarketOrder(.{
    .token_id = "123456789",
    .amount = try Decimal.fromString("100"),  // 100 USDC
    .side = .BUY,
}, &book.value, .{
    .time_in_force = .FOK,  // Fill Or Kill
});

// 创建 FAK 市价卖单（尽可能成交，剩余取消）
const fak_order = try client.createMarketOrder(.{
    .token_id = "123456789",
    .amount = try Decimal.fromString("50"),   // 50 tokens
    .side = .SELL,
}, &book.value, .{
    .time_in_force = .FAK,  // Fill And Kill (IOC)
});

// 创建并发布市价单
const response = try client.createAndPostMarketOrder(.{
    .token_id = "123456789",
    .amount = try Decimal.fromString("100"),
    .side = .BUY,
}, &book.value, .{
    .time_in_force = .FOK,
});
```

### 市价单参数

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| token_id | string | ✅ | Conditional Token ID |
| amount | Decimal | ✅ | BUY: USDC 金额; SELL: token 数量 |
| side | Side | ✅ | BUY 或 SELL |
| fee_rate_bps | u16 | ❌ | 费率（基点），默认 0 |
| max_slippage | Decimal | ❌ | 最大滑点，默认无限制 |

### 订单类型

| 类型 | 描述 | 行为 |
|------|------|------|
| FOK | Fill Or Kill | 必须全部成交，否则整个订单取消 |
| FAK | Fill And Kill | 尽可能成交，未成交部分取消 |

### 市价计算

市价单需要根据订单簿深度计算价格：

```zig
/// 市价计算结果
pub const MarketPriceResult = struct {
    /// 计算出的平均价格
    price: Decimal,
    /// 可以获得的数量
    filled_size: Decimal,
    /// 需要支付的金额
    total_cost: Decimal,
    /// 是否可以完全成交
    fully_fillable: bool,
};

/// 计算市价单价格
/// 
/// 参数:
///   - order_book: 订单簿摘要
///   - side: 交易方向 (BUY 遍历 asks, SELL 遍历 bids)

/// 
/// 返回: 市价计算结果，包含平均价格和成交信息

    side: Side,
```

### 市价单与限价单的区别

| 特性 | 限价单 | 市价单 |
|------|--------|--------|
| 价格 | 用户指定 | 根据订单簿计算 |
| TimeInForce | GTC, GTD | FOK, FAK |
| 执行 | 可能部分成交或挂单 | 立即执行 |
