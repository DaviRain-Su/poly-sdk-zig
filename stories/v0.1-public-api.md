# Story: v0.1-public-api

> **Status**: ⏳ Pending

## Goal

Implement read-only public API endpoints (no authentication required).

## Requirements

### Client Usage

```zig
var client = try poly.Client.init(allocator, .{});
defer client.deinit();

// Server status
const ok = try client.ok();

// Markets
const markets = try client.markets(.{});
const market = try client.market("condition_id");

// Prices
const price = try client.price(.{ .token_id = "..." });
const midpoint = try client.midpoint(.{ .token_id = "..." });

// Order book
const book = try client.orderBook(.{ .token_id = "..." });
```

### Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `ok()` | `GET /` | Server status |
| `serverTime()` | `GET /time` | Server timestamp |
| `markets()` | `GET /markets` | List markets |
| `market(id)` | `GET /markets/{id}` | Single market |
| `price()` | `GET /price` | Token price |
| `midpoint()` | `GET /midpoint` | Mid price |
| `spread()` | `GET /spread` | Bid-ask spread |
| `orderBook()` | `GET /book` | Order book |
| `tickSize()` | `GET /tick-size` | Price increment |
