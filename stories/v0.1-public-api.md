## 目标

## 需求

### 客户端用法

```zig
var client = try poly.Client.init(allocator, .{});
defer client.deinit();

// 服务器状态
const ok = try client.ok();

// 市场
const markets = try client.markets(.{});
const market = try client.market("condition_id");

// 价格
const price = try client.price(.{ .token_id = "..." });
const midpoint = try client.midpoint(.{ .token_id = "..." });

// 订单簿
const book = try client.orderBook(.{ .token_id = "..." });
```

### 端点

| 方法 | 端点 | 描述 |
|------|------|------|
| `ok()` | `GET /` | 服务器状态 |
| `serverTime()` | `GET /time` | 服务器时间戳 |
| `markets()` | `GET /markets` | 市场列表 |
| `market(id)` | `GET /markets/{id}` | 单个市场 |
| `price()` | `GET /price` | 代币价格 |
| `midpoint()` | `GET /midpoint` | 中间价 |
| `spread()` | `GET /spread` | 买卖价差 |
| `orderBook()` | `GET /book` | 订单簿 |
| `tickSize()` | `GET /tick-size` | 价格增量 |
