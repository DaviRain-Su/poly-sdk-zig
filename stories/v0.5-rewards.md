## 目标

实现 Polymarket 奖励和分析相关 API：
1. 订单评分 - 检查订单是否正在获得流动性奖励
2. 价格历史 - 获取市场价格历史数据
3. 市场活动 - 获取市场交易事件

## 背景

Polymarket 提供流动性奖励计划，做市商可以通过提供流动性获得奖励。
奖励基于订单距离中间价的距离、订单大小、双边报价等因素计算。

### 奖励计算规则

- **订单接近中间价**: 越接近得分越高
- **订单大小**: 越大得分越高
- **双边报价**: 同时在买卖两侧报价得分更高
- **时间加权**: 每分钟采样一次

### 主要 API

| API | 基础 URL | 说明 |
|-----|----------|------|
| CLOB API | `https://clob.polymarket.com` | 订单评分 |
| Gamma API | `https://gamma-api.polymarket.com` | 市场数据和奖励配置 |
| Data API | `https://data-api.polymarket.com` | 用户持仓和盈亏 |

## API 设计

### 订单评分

```zig
// 检查单个订单是否正在评分
const scoring = try client.isOrderScoring("order-123");
if (scoring) {
    std.debug.print("Order is scoring for rewards!\n", .{});
}

// 检查多个订单
const results = try client.areOrdersScoring(&.{
    "order-123",
    "order-456",
    "order-789",
});
for (results) |result| {
    std.debug.print("{s}: {}\n", .{ result.order_id, result.scoring });
}
```

### 市场活动

```zig
// 获取市场交易事件
const events = try client.getMarketTradesEvents(condition_id, .{
    .limit = 100,
});
for (events.items) |event| {
    std.debug.print("Trade: {s} @ {s}\n", .{ event.size, event.price });
}
```
