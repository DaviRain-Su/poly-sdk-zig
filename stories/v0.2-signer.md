## 目标

实现钱包签名器，支持从私钥创建钱包、EIP-712 结构化数据签名、订单签名。

## 需求

Polymarket 使用 EIP-712 进行订单签名。需要实现：

1. **Wallet** - 钱包类型，包含私钥和地址
2. **EIP-712 签名** - 结构化数据签名标准
3. **订单签名** - 对 CLOB 订单进行签名

```zig
const signer = @import("signer");

// 创建钱包
const wallet = try signer.Wallet.fromPrivateKey("0x...");
std.debug.print("Address: {s}\n", .{wallet.address});

// EIP-712 签名
const typed_data = signer.TypedData{
    .domain = .{
        .name = "Polymarket CTF Exchange",
        .version = "1",
        .chain_id = 137,
    },
    .types = order_types,
    .primary_type = "Order",
    .message = order_message,
};
const signature = try wallet.signTypedData(typed_data);

// 订单签名（便捷方法）
const signed_order = try wallet.signOrder(order, .{
    .chain_id = 137,
    .neg_risk = false,
});
```

## 技术细节

### EIP-712 签名流程

```
1. hashStruct(typeName, data):
   - typeHash = keccak256(encodeType(typeName))
   - dataHash = keccak256(encodeData(typeName, data))
   - return keccak256(typeHash || dataHash)

2. 完整签名:
   - domainSeparator = hashStruct("EIP712Domain", domain)
   - structHash = hashStruct(primaryType, message)
   - digest = keccak256("\x19\x01" || domainSeparator || structHash)
   - signature = sign(digest)
```

### 签名类型说明

| 类型 | 值 | 使用场景 | 特殊处理 |
|------|---|----------|----------|
| EOA | 0 | MetaMask, 硬件钱包 | 标准签名 |
| POLY_PROXY | 1 | Email/Magic 钱包 | 需要 funder 地址 |
| POLY_GNOSIS_SAFE | 2 | 代理合约 | 需要 funder 地址 |
