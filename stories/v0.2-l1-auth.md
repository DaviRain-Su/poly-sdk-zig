## 目标

实现 L1 级别认证，支持创建和派生 API Key，生成 L1 认证 Headers。

## 需求

L1 认证使用 EIP-712 签名验证钱包所有权，用于：
1. 创建新的 API Key
2. 派生现有的 API Key
3. 签名订单

```zig
const auth = @import("auth");

// 创建 L1 认证器
const l1 = try auth.L1Auth.init(wallet, .{
    .chain_id = 137,
});

// 创建 API Key
const creds = try l1.createApiKey(client);
// => ApiCreds { api_key, api_secret, api_passphrase }

// 派生 API Key（如果已存在）
const creds2 = try l1.deriveApiKey(client);

// 创建或派生（智能选择）
const creds3 = try l1.createOrDeriveApiKey(client);

// 生成 L1 Headers
const headers = try l1.generateHeaders(.{
    .method = .POST,
    .path = "/auth/api-key",
    .body = null,
});
// => L1PolyHeader { POLY_ADDRESS, POLY_SIGNATURE, POLY_TIMESTAMP, POLY_NONCE }
```

## 技术细节

### L1 Header EIP-712 消息

```javascript
// 用于 L1 认证的 EIP-712 消息结构
const types = {
    ClobAuth: [
        { name: "address", type: "address" },
        { name: "timestamp", type: "string" },
        { name: "nonce", type: "uint256" },
        { name: "message", type: "string" },
    ],
};

const domain = {
    name: "ClobAuthDomain",
    version: "1",
    chainId: 137,
};

const message = {
    address: "0x...",
    timestamp: "1704067200",  // Unix timestamp
    nonce: 0,
    message: "This message attests that I control the given wallet",
};
```

### API 端点

| 端点 | 方法 | 描述 | 请求体 |
|------|------|------|--------|
| `/auth/api-key` | POST | 创建新 API Key | - |
| `/auth/derive-api-key` | GET | 派生现有 API Key | - |

### 响应格式

```json
{
    "apiKey": "...",
    "secret": "...",
    "passphrase": "..."
}
```

### 错误码

| 错误 | 描述 | 处理 |
|------|------|------|
| 400 | 签名无效 | 检查签名流程 |
| 401 | 认证失败 | 检查地址匹配 |
| 409 | API Key 已存在 | 使用 derive 代替 |

## 备注

- L1 认证只用于 API Key 管理，不用于常规请求
- 时间戳必须在服务器时间的合理范围内（±30秒）
- Nonce 用于防止重放攻击
- API Secret 和 Passphrase 必须安全存储
