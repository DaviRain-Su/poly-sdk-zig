## 目标

用于 API 请求的 HTTP 客户端封装。

## 需求

### 基本用法

```zig
var client = try HttpClient.init(allocator, .{
    .base_url = "https://clob.polymarket.com",
});
defer client.deinit();

// GET 请求
const response = try client.get("/markets");

// POST 请求
const response = try client.post("/orders", json_body);
```

### 功能

- Base URL 配置
- JSON 请求/响应处理
- 错误映射（HTTP 状态 → SDK 错误）
- 超时处理

## 实现功能

| 功能 | 方法 | 描述 |
|------|------|------|
| GET | `client.get(path, options)` | GET 请求 |
| POST | `client.post(path, body, options)` | 原始 POST |
| POST JSON | `client.postJson(path, value, options)` | JSON POST |
| DELETE | `client.delete(path, options)` | DELETE 请求 |
| DELETE JSON | `client.deleteJson(path, value, options)` | JSON DELETE |
| 查询字符串 | `buildQueryString(params)` | 构建 URL 参数 |
