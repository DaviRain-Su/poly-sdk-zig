## 目标

用于 API 请求的 HTTP 客户端封装。

## 需求

### 基本用法

```zig
var client = try HttpClient.init(allocator, .{
    .base_url = "https://clob.polymarket.com",
});
defer client.deinit();

// GET 请求
const response = try client.get("/markets");

// POST 请求
const response = try client.post("/orders", json_body);
```

### 功能

- Base URL 配置
- JSON 请求/响应处理
- 错误映射（HTTP 状态 → SDK 错误）
- 超时处理
