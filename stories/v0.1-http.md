## Goal

HTTP client wrapper for API requests.

## Requirements

### Basic Usage

```zig
var client = try HttpClient.init(allocator, .{
    .base_url = "https://clob.polymarket.com",
});
defer client.deinit();

// GET request
const response = try client.get("/markets");

// POST request
const response = try client.post("/orders", json_body);
```

### Features

- Base URL configuration
- JSON request/response handling
- Error mapping (HTTP status → SDK error)
- Timeout handling
