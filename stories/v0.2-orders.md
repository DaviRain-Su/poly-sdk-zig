## 目标

实现订单管理 API，支持发布、查询、取消订单，以及交易历史、余额查询等功能。

## 需求

完整的订单管理功能：
1. 发布订单（单个/批量）
2. 查询订单
3. 取消订单
4. 交易历史
5. 账户余额
6. 通知管理

```zig
const client = @import("clob").Client;

// 初始化带认证的客户端
var clob = try client.init(allocator, .{
    .host = "https://clob.polymarket.com",
    .wallet = wallet,
    .api_creds = creds,
});
defer clob.deinit();

// 创建并发布订单
const signed_order = try clob.createOrder(.{
    .token_id = "123456789",
    .price = try Decimal.fromString("0.65"),
    .size = try Decimal.fromString("100"),
    .side = .BUY,
}, .{ .tick_size = .@"0.01" });

const result = try clob.postOrder(signed_order, .GTC);

// 查询订单
const orders = try clob.getOpenOrders(.{});
const order = try clob.getOrder(order_id);

// 取消订单
try clob.cancelOrder(order_id);
try clob.cancelAll();

// 交易历史
const trades = try clob.getTrades(.{});

// 余额查询
const balance = try clob.getBalanceAllowance(.{
    .asset_type = .COLLATERAL,
});
```

### 错误处理

| HTTP 状态 | 错误 | 处理 |
|-----------|------|------|
| 400 | 无效订单 | 检查订单参数 |
| 401 | 认证失败 | 检查 API Key |
| 403 | 无权限 | 检查账户状态 |
| 404 | 订单不存在 | 确认订单 ID |
| 429 | 请求过多 | 添加重试逻辑 |
