## 目标

实现 L2 级别认证，使用 HMAC-SHA256 签名 API 请求，支持所有需要认证的端点。

## 需求

L2 认证使用 API Key + HMAC-SHA256 签名，用于：
1. 订单管理（创建、取消、查询）
2. 交易历史查询
3. 账户余额查询
4. 通知管理

```zig
const auth = @import("auth");

// 创建 L2 认证器
const l2 = try auth.L2Auth.init(wallet.address, api_creds);

// 生成 L2 Headers
const headers = try l2.generateHeaders(.{
    .method = .POST,
    .path = "/order",
    .body = order_json,
});
// => L2PolyHeader { POLY_ADDRESS, POLY_SIGNATURE, POLY_TIMESTAMP, POLY_API_KEY, POLY_PASSPHRASE }

// 在 HTTP 客户端中使用
const response = try client.post("/order", order_json, .{
    .headers = headers.toHttpHeaders(),
});
```

## 技术细节

### HMAC-SHA256 签名算法

```
1. 构造签名消息:
   message = timestamp + method + path + body
   
   示例:
   timestamp = "1704067200"
   method = "POST"
   path = "/order"
   body = '{"tokenId":"123",...}'
   message = "1704067200POST/order{\"tokenId\":\"123\",...}"

2. 计算 HMAC:
   signature = HMAC-SHA256(api_secret, message)

3. Base64 编码:
   encoded = base64(signature)
```

### L2 Header 示例

```http
POLY-ADDRESS: 0x1234567890123456789012345678901234567890
POLY-SIGNATURE: abc123base64signature==
POLY-TIMESTAMP: 1704067200
POLY-API-KEY: your-api-key
POLY-PASSPHRASE: your-passphrase
```

### 使用 L2 认证的端点

| 类别 | 端点 | 方法 |
|------|------|------|
| API Key | `/auth/api-keys` | GET |
| API Key | `/auth/api-key` | DELETE |
| 订单 | `/order` | POST |
| 订单 | `/orders` | POST |
| 订单 | `/data/orders` | GET |
| 订单 | `/data/order/{id}` | GET |
| 订单 | `/order` | DELETE |
| 订单 | `/orders` | DELETE |
| 订单 | `/cancel-all` | DELETE |
| 交易 | `/data/trades` | GET |
| 账户 | `/balance-allowance` | GET |
| 通知 | `/notifications` | GET/DELETE |

### 错误处理

| 错误 | 原因 | 处理 |
|------|------|------|
| 401 | 签名无效 | 检查 HMAC 计算 |
| 401 | 时间戳过期 | 同步服务器时间 |
| 401 | API Key 无效 | 重新获取 API Key |

## 备注

- L2 认证用于所有需要认证的常规请求
- 时间戳必须是秒级 Unix 时间戳
- 签名消息中的 body 必须是原始 JSON 字符串
- 空 body 时，签名消息中不包含 body 部分
- 考虑添加时间戳缓存，避免频繁获取系统时间
