## 目标

实现 Polymarket 认证所需的加密原语：Keccak256 哈希、secp256k1 椭圆曲线签名、HMAC-SHA256。

## 需求

Polymarket API 认证需要以下加密操作：

1. **Keccak256** - 用于 EIP-712 消息哈希、地址计算
2. **secp256k1** - 用于签名生成和验证（ECDSA）
3. **HMAC-SHA256** - 用于 L2 API 请求签名

```zig
const crypto = @import("crypto");

// Keccak256 哈希
const hash = crypto.keccak256("hello");
// => 0x1c8aff950685c2ed4bc3174f3472287b56d9517b9c948127319a09a7a36deac8

// 从私钥派生公钥
const private_key = try crypto.PrivateKey.fromHex("0x...");
const public_key = private_key.publicKey();

// 签名消息
const signature = try private_key.sign(message_hash);

// 验证签名
const valid = public_key.verify(message_hash, signature);

// HMAC-SHA256
const hmac = crypto.hmacSha256(secret, message);
```

## 技术调研

### Zig std.crypto 可用资源

```zig
// Keccak256 - 已在 std 中
const Keccak256 = std.crypto.hash.sha3.Keccak256;

// HMAC-SHA256 - 已在 std 中
const HmacSha256 = std.crypto.auth.hmac.sha2.HmacSha256;

// secp256k1 - 检查 Zig 0.15 是否支持
const Secp256k1 = std.crypto.ecc.Secp256k1;  // 需要验证
```

### secp256k1 实现选项分析

| 选项 | 优点 | 缺点 |
|------|------|------|
| Zig std | 无依赖，纯 Zig | 可能不完整，需要验证 |
| libsecp256k1 | 经过审计，高性能 | 外部依赖，需要绑定 |
| 纯 Zig 实现 | 完全控制，无依赖 | 开发量大，安全风险 |

**建议**: 优先使用 Zig std，如果不可用则使用 libsecp256k1 绑定。

### 以太坊地址计算

```
address = keccak256(public_key)[12:32]
```

公钥是 64 字节（不压缩格式，去掉 0x04 前缀），取 Keccak256 哈希的后 20 字节。
