## 目标

实现批量订单发布功能 (`postOrders`)，支持一次性发布多个订单。

## 需求

批量订单功能允许用户在单个 API 调用中发布多个订单，提高效率并减少网络开销。

```zig
const std = @import("std");
const poly = @import("poly-sdk-zig");
const Decimal = poly.types.Decimal;
const SignedOrder = poly.order.SignedOrder;

// 使用 allocator 创建订单列表
// 注意: Zig 0.15 ArrayList.append 需要 allocator 参数
var orders = try std.ArrayList(SignedOrder).initCapacity(allocator, 2);
defer orders.deinit();

// 添加订单 1
const order1 = try client.createOrder(.{
    .token_id = "123456789",
    .price = try Decimal.fromString("0.55"),
    .size = try Decimal.fromString("100"),
    .side = .BUY,
}, .{});
try orders.append(allocator, order1);

// 添加订单 2
const order2 = try client.createOrder(.{
    .token_id = "123456789",
    .price = try Decimal.fromString("0.45"),
    .size = try Decimal.fromString("50"),
    .side = .SELL,
}, .{});
try orders.append(allocator, order2);

// 批量发布 - 所有订单使用相同的 OrderType
const response = try client.postOrders(orders.items, .GTC);

// 检查结果
if (response.success) {
    // 订单发布成功
    if (response.orderIDs) |ids| {
        for (ids) |id| {
            std.debug.print("Order ID: {s}\n", .{id});
        }
    }
}
```

### 请求格式

```json
{
  "orders": [
    {
      "order": { /* SignedOrder */ },
      "orderType": "GTC"
    },
    {
      "order": { /* SignedOrder */ },
      "orderType": "GTC"
    }
  ]
}
```

### 响应格式

```json
{
  "success": true,
  "orderIDs": ["order-id-1", "order-id-2"],
  "errors": []
}
```

## 技术细节

### API 端点

```
POST /orders
```

### 请求结构

```zig
pub const PostOrdersRequest = struct {
    orders: []const OrderWithType,
    
    pub const OrderWithType = struct {
        order: SignedOrder.OrderDataView,
        orderType: []const u8,  // "GTC" | "GTD" | "FOK" | "FAK"
    };
};
```

### 响应结构

```zig
pub const PostOrdersResponse = struct {
    success: bool,
    orderIDs: []const []const u8,
    errors: []const OrderError,
    
    pub const OrderError = struct {
        index: usize,
        message: []const u8,
    };
};
```

### 错误处理

批量订单可能部分成功。需要处理：

1. **全部成功**: `success = true`, `errors = []`
2. **部分成功**: `success = true`, `errors` 包含失败的订单
3. **全部失败**: `success = false`
