## 目标

实现订单构建器，支持创建限价单和市价单，计算价格和数量，签名订单。

## 需求

订单构建器负责：
1. 从用户参数构建订单结构
2. 计算 maker/taker 金额
3. 生成随机 salt
4. 签名订单

```zig
const order = @import("order");

// 创建订单构建器
var builder = try order.OrderBuilder.init(allocator, wallet, .{
    .chain_id = 137,
});
defer builder.deinit();

// 创建限价单
const limit_order = try builder.createOrder(.{
    .token_id = "123456789",
    .price = try Decimal.fromString("0.65"),
    .size = try Decimal.fromString("100"),
    .side = .BUY,
}, .{
    .tick_size = .@"0.01",
    .neg_risk = false,
});

// 创建市价单
const market_order = try builder.createMarketOrder(.{
    .token_id = "123456789",
    .amount = try Decimal.fromString("100"),  // 100 USDC
    .side = .BUY,
}, .{
    .tick_size = .@"0.01",
    .order_book = order_book,  // 需要订单簿计算价格
});

// 计算市价
const market_price = try builder.calculateMarketPrice(
    order_book,
    try Decimal.fromString("100"),
    .BUY,
);
```

## 技术细节

### 金额计算公式

```
限价单:
- BUY:  maker_amount = price * size (支付 USDC)
        taker_amount = size (获得 token)
- SELL: maker_amount = size (支付 token)
        taker_amount = price * size (获得 USDC)

市价单:
- BUY:  根据订单簿计算能买到的 token 数量
- SELL: 根据订单簿计算能卖出的 USDC 数量
```

### Tick Size 处理

```zig
// 价格必须是 tick_size 的整数倍
fn roundToTickSize(price: Decimal, tick_size: TickSize) Decimal {
    const tick = tick_size.toDecimal();
    const rounded = price.div(tick).floor().mul(tick);
    return rounded;
}
```

### 市价计算示例

```
订单簿 (asks):
| 价格 | 数量 |
|------|------|
| 0.65 | 100  |
| 0.66 | 200  |
| 0.67 | 150  |

买入 250 个 token:
- 100 @ 0.65 = 65 USDC
- 150 @ 0.66 = 99 USDC
- 总计: 164 USDC
- 平均价格: 164/250 = 0.656
```

### SignedOrder 结构

```zig
pub const SignedOrder = struct {
    /// 随机盐值 (防止订单 ID 冲突)
    salt: u256,
    /// 订单创建者地址
    maker: Address,
    /// 签名者地址 (通常与 maker 相同)
    signer: Address,
    /// 接单者地址 (零地址 = 公开订单)
    taker: Address,
    /// Token ID
    token_id: []const u8,
    /// Maker 金额 (以最小单位计)
    maker_amount: u256,
    /// Taker 金额 (以最小单位计)
    taker_amount: u256,
    /// 过期时间戳
    expiration: u64,
    /// Nonce (用于链上取消)
    nonce: u64,
    /// 费率 (基点)
    fee_rate_bps: u16,
    /// 交易方向
    side: Side,
    /// 签名类型
    signature_type: SignatureType,
    /// EIP-712 签名
    signature: [65]u8,
};
```
