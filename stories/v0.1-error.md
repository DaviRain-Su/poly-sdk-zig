## 目标

定义 SDK 的错误类型。

## 需求

### 错误分类

```zig
pub const Error = error{
    // 网络
    ConnectionFailed,
    Timeout,
    
    // HTTP
    BadRequest,
    Unauthorized,
    Forbidden,
    NotFound,
    RateLimited,
    ServerError,
    
    // 解析
    InvalidJson,
    InvalidDecimal,
    InvalidAddress,
    
    // 验证
    InvalidPrice,
    InvalidSize,
    InvalidTokenId,
    
    // 认证
    MissingCredentials,
    InvalidSignature,
    ExpiredCredentials,
};
```

### 错误上下文

```zig
pub const ErrorContext = struct {
    code: Error,
    message: []const u8,
    http_status: ?u16 = null,
    retry_after: ?u64 = null,  // 用于速率限制
};
```
