## 目标

实现 Builder API Key 管理功能，支持做市商程序的专用认证流程。

## 需求

Builder 是 Polymarket 的做市商程序认证机制。Builder API Key 具有特殊权限，可以访问做市商专用端点。

```zig
const clob = @import("clob");

// 创建 Builder API Key
const builder_key = try client.createBuilderApiKey();
std.debug.print("Builder API Key: {s}\n", .{builder_key.api_key});

// 获取所有 Builder API Keys
const keys = try client.getBuilderApiKeys();
for (keys.value) |key| {
    std.debug.print("Key: {s}, Created: {s}\n", .{key.api_key, key.created_at});
}

// 撤销 Builder API Key
try client.revokeBuilderApiKey(builder_key.api_key);

// 使用 Builder 配置初始化客户端
var client = ClobClient.initWithBuilder(allocator, .{}, &wallet, &creds, &builder_creds);

// 获取 Builder 交易历史
const trades = try client.getBuilderTrades(.{});
```

## 技术细节

### Builder Header 格式

Builder 请求需要额外的 Header 字段：

```typescript
interface L2WithBuilderHeader extends L2PolyHeader {
    POLY_BUILDER_API_KEY: string;
    POLY_BUILDER_TIMESTAMP: string;
    POLY_BUILDER_PASSPHRASE: string;
    POLY_BUILDER_SIGNATURE: string;
}
```

### Builder 配置

```zig
pub const BuilderCreds = struct {
    api_key: Secret([]const u8),
    api_secret: Secret([]const u8),
    passphrase: Secret([]const u8),
    
    /// 验证配置是否有效
    pub fn isValid(self: *const BuilderCreds) bool {
        return self.api_key.reveal().len > 0 and
               self.api_secret.reveal().len > 0 and
               self.passphrase.reveal().len > 0;
    }
    
    /// 生成 Builder Header
    pub fn generateHeaders(

        method: []const u8,
        path: []const u8,

};
```

### API 端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/auth/builder-api-key` | POST | 创建 Builder API Key |
| `/auth/builder-api-key` | GET | 获取所有 Builder API Keys |
| `/auth/builder-api-key` | DELETE | 撤销 Builder API Key |
| `/builder/trades` | GET | 获取 Builder 交易历史 |

## 备注

- Builder 功能主要面向专业做市商
- Builder API Key 权限高于普通 API Key
- 需要额外的安全考虑（密钥保护等）
- 参考 TypeScript 客户端 `createBuilderApiKey()` 实现
