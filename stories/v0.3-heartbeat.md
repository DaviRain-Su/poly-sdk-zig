## 目标

实现 Heartbeat 端点，用于保持 API 连接活跃并防止订单自动取消。

## 需求

Polymarket CLOB API 要求活跃的做市商定期发送心跳信号。如果在 10 秒内未收到心跳，系统会自动取消该用户的所有订单。

```zig
const clob = @import("clob");

// 发送心跳
const response = try client.postHeartbeat();
std.debug.print("Heartbeat sent, orders kept alive\n", .{});

// 在后台线程中持续发送心跳
const heartbeat_thread = try std.Thread.spawn(.{}, heartbeatLoop, .{&client});
```

### 心跳循环示例

```zig
fn heartbeatLoop(client: *ClobClient) void {
    while (running) {
        client.postHeartbeat() catch |err| {
            std.log.err("Heartbeat failed: {}", .{err});
        };
        std.time.sleep(5 * std.time.ns_per_s);  // 每 5 秒发送一次
    }
}
```

## 技术细节

### API 端点

```
POST /v1/heartbeats
```

**注意**: 此端点使用 `/v1/` 前缀，与其他端点不同。

### 请求

空 JSON 对象：

```json
{}
```

### 响应

```json
{
  "success": true
}
```

### 心跳规则

1. **发送频率**: 建议每 5-8 秒发送一次
2. **超时时间**: 10 秒内未收到心跳会取消所有订单
3. **适用场景**: 主要用于做市商程序

### 实现注意事项

```zig
pub const Endpoints = struct {
    // ...existing endpoints...
    
    // Heartbeat (注意不同的路径前缀)
    pub const HEARTBEAT = "/v1/heartbeats";
};

pub fn postHeartbeat(self: *ClobClient) !HeartbeatResponse {
    const response_body = try self.doAuthPost(Endpoints.HEARTBEAT, "{}");
    defer self.allocator.free(response_body);
    
    const parsed = std.json.parseFromSlice(HeartbeatResponse, self.allocator, response_body, .{
        .ignore_unknown_fields = true,
    }) catch return Error.InvalidJson;
    defer parsed.deinit();
    
    return parsed.value;
}
```

## 备注

- 心跳是可选功能，只有需要长时间保持订单活跃的用户才需要使用
- 普通用户不需要发送心跳，订单会一直保持直到成交或取消
- 心跳失败不应该导致程序崩溃，应该记录日志并重试
